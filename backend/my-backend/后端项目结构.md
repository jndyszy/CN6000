# 后端项目结构（Go + Gin）

```
my-gin-app/
├── conf/               # 配置文件 (config.yaml, settings.go)
├── controller/         # 【重要】接口层：解析参数，调用 Service，返回 JSON
│   ├── user_controller.go
│   └── ping_controller.go
├── dao/                # 【重要】数据访问层 (Data Access Object)：SQL 操作
│   └── user_dao.go
├── middleware/         # 自定义中间件 (CORS, JWT校验, 日志记录)
│   └── cors.go
├── model/              # 【重要】模型层：数据库实体定义 (GORM Tags)
│   └── user.go
├── repository/         # (可选) 仓库层：介于 Controller 和 Dao 之间
├── router/             # 路由定义：将 URL 绑定到 Controller 方法
│   └── router.go
├── service/            # 【重要】业务逻辑层：核心逻辑处理
│   └── user_service.go
├── utils/              # 工具类 (加密、MD5、时间转换)
├── go.mod              # 依赖管理文件
├── go.sum              # 依赖锁定文件
└── main.go             # 项目入口：启动服务
```

## 请求流转链路

```
HTTP Request
    │
    ▼
router/          # 路由匹配，绑定中间件
    │
    ▼
middleware/      # JWT 鉴权、限流、CORS 等前置处理
    │
    ▼
controller/      # 解析请求参数，入参校验，调用 Service
    │
    ▼
service/         # 核心业务逻辑，编排多个 Dao 调用
    │
    ▼
dao/             # 执行 SQL / GORM 操作，与数据库交互
    │
    ▼
model/           # 数据库实体结构体定义
```
